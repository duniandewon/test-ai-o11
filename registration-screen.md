# Registration Screen

## Requirements

- Screen should be accessed by everyone (Anonymous)
- Screen should contain a form with first name, last name, email, and a submit button.
- Submit button is first disabled, but when all fields are filled, submit button becomes enabled.
- Clicking on submit button will show an alert message containg the values of text inputs, and reset form.

## Components to use

- Text input: TextInputWithBordersRounded
- Button: PrimaryLarge
